# Controls

This folder contains the shared material that keeps the dataset comparable across providers and model settings.

Use `prompt-bank.md` for controlled prompt topics, `metadata-schema.md` for required transcript fields, and `coding-guide.md` for post-hoc sycophancy labels.

The full team-authored dataset is preserved in `prompt-dataset.csv`. `prompt-dataset.json` is an exact field-for-field mirror used to select rows during automated collection.
